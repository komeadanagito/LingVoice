# 部署验收记录（2026-11-14）

## 已完成

- 四份官方模型：Qwen3-ASR-1.7B、Qwen3-ForcedAligner-0.6B、Gemma 4 E2B，以及 GPT-SoVITS V5 Turbo/Dev 与推理必要资源，均已下载到本项目并校验。具体 revision、文件大小和 SHA-256 见各模型清单。
- 三个模型服务分别使用独立虚拟环境。ASR 和翻译为 Python 3.12.16 / torch 2.10.0+cu128 / Transformers 5.23.0；V5 为 Python 3.10.22 / torch 2.6.0+cu126 / Transformers 4.51.3。依赖检查通过，用户 site 被禁用。
- ASR 和对齐器在 CUDA 上顺序加载、公开英文短样本识别和真实词级对齐通过；加入跨进程 GPU 锁后再次离线推理通过。模型时间戳可能存在相邻词重叠，本插件保留并报告，不通过比例分配伪造精确时间。
- Gemma E2B 的 Windows NF4 CUDA 算子、完整模型加载、两句英文到中文的离线推理通过，进程峰值 CUDA 分配约 6467.1 MiB。该短测试含加载约 20.91 秒，不是完整视频速度基准。
- V5 Turbo 和 Dev 均在 CUDA 加载通过，Turbo 也在 CPU 加载通过。加入跨进程锁和离线网络保护后，Turbo 再次 CUDA 加载通过（约 10.34 秒，加载阶段峰值 2,322,021,376 字节）。中文、英文、日文、粤语、韩文文本前端通过。
- 根管理入口已验证翻译和 V5 的前台启动、127.0.0.1 健康检查、进程身份核验及停止；V5 GPU 服务在端口 9873 实际返回 ready，之后已停止。
- 27 项插件控制面测试通过：ASR 14 项、共享/翻译 6 项、V5 7 项。包含请求边界、路径限制、浏览器来源限制、克隆授权声明、GPU 文件锁互斥和 V5 离线外连阻断。
- 原项目 TypeScript 检查 `npm run check` 通过。`npm test` 为 234 通过、2 失败、1 跳过；两个失败均是 Windows EPERM（history 测试清理只读目录、web-backend 测试创建符号链接）。在非沙箱重试后仍然如此，未修改原测试或相关业务代码来掩盖问题。

## 仍未验证的内容

- V5 **没有生成克隆音频**，因为尚未提供有授权的参考声音；音色相似度、实际合成速度及合成峰值显存未验证。加载阶段显存不能作为合成显存上限。
- 没有完成 10 分钟视频的全流程或多语言准确率基准。
- 尚未把本地插件接入 Electron 界面、现有 ASR/翻译/云端克隆业务流程；启动原应用不会自动切换后端。
- 环境隔离不隔离 GPU 容量或系统驱动；模型应按阶段运行。Gemma 已验证的 8 GB 显存余量有限，应避免其他 GPU 重负载。

当前没有刻意保留运行中的模型服务。操作入口和协议见 `README.md`，当前安装/下载状态可用 `plugins.ps1 -Action check` 重新检查。实际服务健康接口与静态验收记录应分别理解，健康接口也不代表克隆质量已通过。
